# Claude Code Mods — Deep Research Board Tutorial

20-slide bilingual (EN/ZH) deck. Learn the Mods API by building a **Deep Research Board** — a live scoreboard of sources and progress above the prompt — instead of the harder-to-grasp “Token Weather” meter in the official post.

Official API reference: [Getting started with Claude Code mods](https://claude.dev/blog/getting-started-with-claude-code-mods/)

## Why this example

| Official example | This tutorial |
| --- | --- |
| Token Weather (context % as weather) | Deep Research Board (sources / claims / status) |
| Abstract meter | Everyday agent workflow people already know |

Same mechanics: `register(on)`, observe / rewrite / answer, `$.state`, `AbovePrompt`, validate / test / marketplace.

## Open locally

Open `index.html`, or:

```bash
npx --yes serve .
```
